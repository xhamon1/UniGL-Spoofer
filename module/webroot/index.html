Device profiles cannot be edited or deleted. Only custom profiles can.

Full or Minimal?

Minimal changes only the GPU strings (OpenGL ES renderer and vendor, Vulkan device name), the manufacturer and the model. Start here.

Full changes everything above and also the Vulkan vendor ID, brand, board, hardware and SoC model/manufacturer. Use it only if Minimal does not unlock the graphics settings. Changing more properties can make some games behave differently or crash.

Custom lets you write your own profile. Every key is optional; an empty value leaves the real value untouched.
